# Subagents: Key Ideas

1. Context is the scarce resource. Subagents spend their own context so yours stays clean.
2. Delegation is a handoff, not a shared brain. Write the task message as if to a new colleague.
3. Narrow beats general. One job, the fewest tools, a clear finish line.
4. Shape the return. A fixed output format makes summaries short and usable.
5. Report obstacles, do not hide them. A good subagent says what blocked it and what it got done.
6. The description is the routing rule. Keep descriptions distinct.
7. Delegate when the work is self-contained or noisy; stay in the main thread when it is iterative.
8. Parallelize only independent work, and remember each subagent costs tokens.
