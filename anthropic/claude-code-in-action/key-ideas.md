# Claude Code in Action: Key Ideas

1. Scope before you build. Plan mode is cheap; rework is not.
2. Context is a budget. Compact with intent and rewind early when a session drifts.
3. Instructions guide, hooks guarantee. Put every must-never-fail rule in a hook.
4. Keep CLAUDE.md short facts; move procedures into skills.
5. Match the permission mode to the risk and how closely you are watching.
6. Repeat work becomes automation: schedules, headless runs, PR integration.
7. Verify in proportion to how little you supervised. Real tests, not the summary.
8. A setup you trust is worth packaging. Plugins make it one install for the team.

Sources: https://code.claude.com/docs/en/overview
