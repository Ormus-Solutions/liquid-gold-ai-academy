## Layout

Each course folder holds `NOTES.md`, `key-ideas.md`, `prompts/` and `skills/`. The `synthesis/` folder gathers what every course agrees on. `plugins/` holds anything packaged for reuse. Progress lives in [PROGRESS.md](PROGRESS.md).
